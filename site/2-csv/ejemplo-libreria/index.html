    2.3. Ejemplo con librerías: Papa Parse + Tabulator

    En el ejemplo anterior procesamos el CSV manualmente con JavaScript puro.
    Ese método es muy útil para aprender, pero puede volverse complicado si el archivo es grande o si contiene detalles como comillas, saltos de línea en campos o separadores distintos.

    Para resolver estos problemas podemos usar librerías que simplifican el trabajo:
    - Papa Parse: para leer y convertir CSV en objetos JavaScript de forma automática.
    - Tabulator: para mostrar los datos en tablas dinámicas, con búsqueda, ordenación y paginación sin necesidad de programarlo todo a mano.

    📌 Parsear un CSV con Papa Parse

    Papa Parse es una librería muy usada en proyectos web.
    Permite convertir un CSV en un array de objetos con solo unas líneas:

    fetch("datasets/csv/hosteleria-a-domicilio.csv")
  .then(res => res.text())
  .then(texto => {
    let resultado = Papa.parse(texto, { header: true, skipEmptyLines: true });
    console.log(resultado.data.slice(0, 5));
  });

    En este ejemplo:

    • header: true indica que la primera línea son las cabeceras.
    • skipEmptyLines: true evita problemas si hay líneas en blanco.
    • resultado.data contiene un array de objetos con los datos del CSV.

    Consejo

    Papa Parse detecta automáticamente si el separador es , o ;, por lo que no necesitas preocuparte de ese detalle.

    📌 Mostrar los datos con Tabulator

    Tabulator es una librería que convierte un div en una tabla interactiva. Podemos usarla para mostrar el dataset de hostelería de forma más cómoda:

    new Tabulator("#tabla", {
  data: resultado.data,
  layout: "fitDataStretch",
  pagination: true,
  paginationSize: 10,
  columns: Object.keys(resultado.data[0] ?? {}).map(k => ({
    title: k,
    field: k
  }))
});

    Con esta configuración básica:

    • layout: "fitDataStretch" ajusta las columnas al ancho disponible.
    • pagination: true activa la paginación automática.
    • paginationSize: 10 muestra 10 registros por página.
    • columns se generan dinámicamente a partir de las cabeceras del CSV.

    📌 Comparación con el enfoque vanilla

    • Vanilla JS:

      • Tú controlas cada paso del parseo y la construcción de la tabla.
      • Útil para aprender, pero puede ser tedioso con datos grandes.

    • Con librerías:

      • Papa Parse gestiona automáticamente los detalles del CSV.
      • Tabulator ofrece interfaz profesional sin apenas programar.
      • Ideal para proyectos reales donde prima la rapidez y la robustez.

    Consejo

    Aunque las librerías nos ahorran mucho trabajo, es fundamental entender antes el proceso manual. Así, cuando algo falle o quieras personalizarlo, sabrás cómo funciona por dentro.
